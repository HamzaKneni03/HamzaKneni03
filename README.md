### 🚀 Featured Projects

#### 📶 STM32WLE5 – LoRaWAN IoT Monitoring System

Development of an IoT monitoring node based on the **STM32WLE5JC** microcontroller, using LoRaWAN communication for wireless data transmission to an IoT network server.

- Hardware study and documentation of the Wio-E5 Development Kit.
- LoRaWAN configuration using AT commands.
- Communication tests with The Things Network (TTN).
- Exploration of MQTT-based IoT integration.

#### 💧 Wireless Water Tank Management & Pump Protection System

Development of a multi-node wireless water management system using four ESP32 boards communicating through **ESP-NOW**. The system monitors water levels, controls a water pump, and protects it against dry running and tank overflow.

- Four-node ESP32 architecture.
- Wireless communication using ESP-NOW.
- Water level monitoring using HC-SR04 ultrasonic sensors.
- Automatic pump control and protection using a relay.
- OLED monitoring and Blynk dashboard integration.
